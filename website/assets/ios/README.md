# Trippin Remote (iOS) media

Screenshots and the App Store preview video of Trippin Remote, the iPhone
and iPad app that controls Trippin over Wi-Fi. They come from the app's
built-in demo mode. The scene thumbnails are real Trippin renders, and the
now-playing tracks are made-up names. Status bars show 9:41.

- **Needs:** Trippin running on a Mac or Windows PC on the same network, with the remote turned on in Trippin's Settings. Free.
