Set up

Connected in three steps

Turn it on

In Trippin, open Settings and switch on the remote. It shows an address and a pairing PIN.

Join the same Wi-Fi

Put your phone or iPad on the same network as the computer running Trippin. It finds it automatically.

Enter the PIN

Pair once. The PIN is kept in your device's Keychain, so next time it's one tap.

No rig handy? Tap Try the demo inside the app, no computer needed.
Prefer no install? Browse to http://<your-computer-ip>:9138 on any device for a basic web remote. OSC for TouchOSC is supported too.
