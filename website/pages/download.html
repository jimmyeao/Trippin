A small tray app for the machine that runs your DJ software. It tells a Trippin on another computer what's playing. How it works

Windows

Zip. Unpack it and run it; it lives in the system tray.

macOS

Zip. Unpack it and run it; it lives in the menu bar. If macOS blocks it, open it once and allow it in System Settings → Privacy & Security → Open Anyway.

Download agent (.zip)

You need the full Trippin on the second machine, with the remote turned on in Settings. The agent finds it on your network and pairs with the same PIN as the iPhone remote.

Good to know

Requirements

A decent GPU

Built to hold 60 fps on an RTX 3060 or an Apple M2. The heaviest 3D scenes switch themselves off on weaker graphics, and integrated GPUs get a lighter mode.

Audio

Captures whatever your computer is playing. On Mac, DJ software routed straight to a controller's own audio interface needs that device chosen as the audio input in Settings.
